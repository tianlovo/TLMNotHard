# 0.1.0-beta.1

TLMNotHard 首个公开 Beta，目标环境为 GTNH 2.9.0、Minecraft 1.7.10、Forge 10.13.4.1614，游戏使用 Java 25。

## 本次内容

- 基于当前已集成的女仆交互、背包与双手、模型、配音、获取与复活、睡觉、零食柜和 GTNH 配方功能发布测试版本。
- Enhanced 统一战斗、已知箭威胁避险及第一部分工程收口成果。
- 第二部分行为会话组件化，包括扩展注册、生命周期、动作入口、故障隔离和受限命名空间存档。
- 完整保留已纳入的模型、贴图、动画、435 个配音及 10 个基础音效。原作者署名、来源清单和许可证随 JAR 提供。

## 安装

1. 从本页 Assets 下载 `tlmnh-0.1.0-beta.1.jar`，按 `SHA256SUMS.txt` 核对 SHA-256。
2. 正常停止客户端和服务端，备份完整世界、两端配置及旧 TLM JAR。
3. 将相同 JAR 放入两端的 `mods/`，将旧 TLM JAR 移出该目录，再启动两端。

新配置默认 Enhanced，已有显式 Legacy 设置继续生效。控制与配置见仓库 `docs/USER_GUIDE.md` 和英文版。
降级时应成对恢复旧 JAR、完整世界及配置，具体步骤见使用说明。

- `LEGACY-GROUND-001` 待处理。Legacy 地面跟随用例在两个相邻候选上均于第 14 tick 触发位移平方小于 1 的守卫，完整四项原生批次记录为 3 项通过、1 项失败。
- `COMBAT-STATS-001` 待处理。共有战斗统计预览 v3 尚待审查，正式协议和实际 seed/顺序采集绑定待补，统计结论尚未签署。
- 四项生存与装备适配、真实饥饿和治愈之斧仍待实现，包括落水/坠落自救、太空供氧、纳米/量子装备及热锭防护。
- 源码重构与硬编码、外部 NBT、复杂度治理将合并迭代。带 NBT 物品的真实 Shift 操作、最终候选的跨模块组合、双端兼容及玩家验收仍待完成。

## 验证记录

源码基线 `d3f3efe` 的第二部分候选已实际执行并通过 490 项主单测及 97 项客户端检查。
原生关联验证通过低氧抢占与物品返还、挂起/存档往返、短 32 实体配额三项，Legacy 守卫失败记录保留。
第一部分的已知箭、共有回放、双客户端和三轮持续负载证据绑定各自历史候选，详细记录见 `PROGRESS.md`。
本次 Beta 的构建与包内版本、字节码、资产和许可检查以随发布提供的构建记录为准。
